# Project description
This is a small project designed to make a repetitive process at work easier to go about. It took roots as a Python project, and has now progressed to a static web application that relies on React to perform simple calculations with a neat looking UI. The back end logic was developed by myself, but the UI remains the outcome of Artifical Intelligence (that is, until I figure out what all of those fancy CSS terms mean).
